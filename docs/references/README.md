当前三篇主要依据：

- [Xia–Yang 2016](<triangular-set/Xia 和 Yang - 2016 - Automated Inequality Proving and Discovering.pdf>)：三角列分解算法。

- [Xia–Yang 2002](<triangular-set/Xia和Yang - 2002 - An Algorithm for Isolating the Real Solutions of Semi-algebraic Systems.pdf>)：补充参考。
