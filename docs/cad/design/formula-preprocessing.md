# 实数多项式公式的线性等式预处理

本层用于量词自由实多项式公式的可满足性求解：先用必须成立的线性等式消元，化简公式，再对剩余变量调用既有 `full_cad`。当前已完成独立实验原型，尚未并入库的公共接口。数据结构与消元算法分离，QQ、三角列及 CAD 原有契约保持不变。

## 范围与模块边界

公式由 QQ 多项式表和子句列表组成。原子为 `p=0`、`p>0` 或 `p<0`；同一子句内取或，不同子句之间取且。变量均取实数，可满足性按对全部自由变量作存在量化解释。

预处理结果保存剩余变量、化简公式、原变量的恢复表达式和消元步骤。独立算法负责选择等式、QQ 消元、代入及子句化简；结果类型仅保存数据。

流程为：

```text
原公式 F(X)
    → 线性等式消元、常量化简、恢复映射 X=R(U)
    → 剩余公式 G(U)
    → 若已有确定真值，直接返回
    → 否则对 G 的多项式调用 full_cad，按叶符号判断子句
    → 将满足 G 的样本通过 R 解释为原公式的解
```

本层不放入 `full_cad` 内部。`full_cad` 的输入是多项式及变量序，要求分解整个输入空间；它不接收哪些等式必须成立。删除变量后构造的是剩余空间的 CAD，恢复映射描述的是约束解集，不是原空间的完整 CAD，也不保证对原变量序仍保持柱形性。

当前范围不包括整数消元、跨量词前缀的代换、析取分支展开、一般非线性等式求解，以及除以符号未知或可能为零的多项式。

## 功能规格

输入要求：变量无重复，覆盖多项式中的全部变量；各多项式满足库的规范化不变量；子句引用有效多项式编号。

输出满足：

1. 剩余变量 U 是原变量 X 的子集；恢复映射 R 的每个分量都是 QQ 仿射多项式，保留变量的分量是自身。
2. 对所有实数赋值 u，`F(R(u))` 当且仅当 `G(u)`。
3. 每个满足 F 的 x 都满足 `x=R(x|U)`，且其限制赋值满足 G。
4. 因此 `存在 X: F(X)` 当且仅当 `存在 U: G(U)`。

未消元的变量即使暂不出现在 G 中，仍是自由参数，不能误判为唯一解。若 G 为真，可选择这些参数为零得到一个见证；若 G 为假，则原公式无解。

## 允许的消元与代入

只选择单原子子句 `p=0`，且 p 的总次数至多为 1。写成

```text
c*v + r(U) = 0，c ∈ QQ，c ≠ 0
```

得到 `v=-r/c`。QQ 域中的除法精确；代入所有多项式和已有恢复表达式后，保留 QQ 系数。循环重新查找线性等式，因为非线性方程经常量代入后可能变成线性方程。

例如 022 的 `3*b-6=0` 给出 b=2，再由 `4*a+5*b+2=0` 得 a=-3；否定结论 `a+b+1≠0` 变成 `0≠0`，直接判定无解。015 中 x 和 factor 确定后，含其乘积的方程也依次成为可消去的线性方程。

`x=0 | y=0` 中任何一边都不一定成立，不能直接采用。若先由独立子句确定 x=1，原析取化简成 y=0，则新产生的单原子等式可以采用。

`a*x+b=0` 的 a 若是变量，不满足常数主元条件；不能直接写成 `x=-b/a`。例如 `a*x=0` 包含 a=0 的整条分支，除以 a 会丢解。

单个变量的一次方程、但其他变量可能非线性的定义式，如 `area-s*s=0`，可以另行设计常数系数定义消元；它不属于本次总次数至多为 1 的实验范围。

## 完整伪代码

```text
LINEAR-PREPROCESS(F, X):
    P := F 的 QQ 多项式表
    C := F 的子句表
    U := X
    R[x] := x，对每个 x ∈ X
    steps := 空列表

    循环:
        对 C 中每个原子:
            若其多项式为常量，精确计算原子的真值
        删除含真原子的子句
        从其余子句中删除假原子
        若出现空子句，返回 (假公式, U, R, steps)
        若没有子句，返回 (真公式, U, R, steps)

        找单原子子句 p=0，要求 p 总次数至多 1 且非常量
        若不存在，结束循环

        选 p 中系数 c 非零的变量 v
        写 p=c*v+r；s := -r/c
        记录 (p, v, c, s)
        将 P 中全部多项式的 v 替换为 s，并规范化
        将 R 中全部表达式的 v 替换为 s，并规范化
        从 U 中删除 v

    移除未被子句引用的多项式，重建引用编号
    返回 (剩余公式, U, R, steps)
```

选择顺序影响规模，不影响正确性。实验优先选择只含一个变量的方程，再选稀疏方程；相同条件下优先消去变量表中靠后的变量，使常见辅助变量先被消去。总次数至多 1 的非零多项式必存在非零 QQ 主元。

## 正确性与终止性

**单步等价。** 对实数 u，由 c 非零，有 `c*v+r(u)=0` 当且仅当 `v=-r(u)/c`。该等式单独成句，是原公式的必要条件。因此消去 v 后的其余公式恰好描述原公式在这张仿射图上的取值；不存在额外非零或符号分支。

**恢复不变量。** 初始 R 是恒等映射。每步将同一代换应用于公式和 R，保持 `F(R(u)) ⇔ G(u)`。对任一原满足赋值，主元等式唯一确定被消变量；归纳得该赋值等于恢复其剩余坐标所得的赋值。由此得到规格中的双向结论，而不只是由化简解生成原解的单向结论。

**布尔化简。** 常量原子用精确 QQ 比较求值。删除含真原子的子句、删除假原子均保持公式等价；空子句为假，空子句列表为真。不能把二者都表示为空列表而忽略结果状态。

**代入保持。** 对多项式逐项以 `系数 × 各代换表达式的整数幂` 展开并合并同类项，由环运算恒等式保持取值。代入所有约束，包括不等式，不额外对多项式乘以未记录符号的因子。

**终止。** 每个成功步骤删除一个仍在 U 中的变量；至多进行原变量数次。多项式代入和规范化均为有限操作。仿射代换不增加多项式总次数，但可能增加项数和 QQ 位数，故不承诺所有输入都加速。

## 与现有库的实现对应

常量代入可复用 `polynomial.hh::assign(f,v,q)` 或多变量 QQ 映射入口。现有这些入口代入的是标量；仿射多项式代入须由 QQ 多项式的加法、乘法和整数幂组合实现，不能误称既有 `assign` 已直接支持多项式值代换。

剩余公式的多项式交给原 `full_cad`，子句由叶上的原输入符号求值。恢复表达式先作为 QQ 多项式及其输入实点上下文解释；输出原坐标的独立实点证书需要另行实现并验证，不能把普通区间包络当作恢复点。

后续 C++ 精化须证明：QQ 主元除法精确；替换时比较器有效且变量序一致；规范化保持多项式值；子句编号重建正确；恢复表达式只引用剩余变量；算法函数与结果数据分离。当前脚本原型使用精确有理运算，不代替库内 QQ 实现的精化证明。

## 实验与验证边界

实验输入为新版 FormalMath500 的 60 个子句文件。预处理单独直接判定 36 题，其中 27 题无解、9 题有解；其余 24 题继续调用既有 CAD。前处理不调用 Z3 作决定，Z3 只用于独立对照。

对全部 60 题检查了恢复映射下原公式与剩余公式的异或不可满足。该检查验证映射上的布尔等价；原解均可恢复的结论由上述主元不变量证明，不能只凭两式的 SAT 标签相同认定等价。另检查了析取保护、未知系数为零的分支、矛盾等式及负系数代换下的严格不等式。

同样使用 GCC 13.4.0、`-O2 -DNDEBUG` 测试翻译单元及既有 Debug 静态库，每种变量序限时 10 秒，首序超时后尝试反序。直接 CAD 完成 46 题，前处理加剩余 CAD 完成 56 题，均与独立结果一致，无已完成题退化为超时。尚未完成的是 054、055、056、058。其中 054、055、058 没有可直接采用的线性等式；056 由五变量降为四变量，仍需处理非线性约束。

053 从四变量降为一变量，057 从五变量降为三变量。预处理直接判为有解的 9 题，另将自由参数取零，按恢复映射生成原坐标，并用精确有理运算检查全部原始子句。化简后 CAD 样本的原坐标表达式可按规格解释，但本原型没有输出新的完整原坐标实点证书。

历史实验原型、恢复映射、残余公式和验证脚本曾位于 `/private/tmp/clpoly-formalmath500-linear-20261022/`；归档现见[三数据集报告](../reports/three-datasets.md)，当前工具和回归入口见[工具说明](../reports/three-datasets/README.md)。计时区分脚本预处理、CAD 与进程启动，不把脚本速度作为未来 C++ 实现的性能保证。基础 CAD 中平方自由分解的系数膨胀仍须独立处理，前处理只减少触发该路径的公式。
