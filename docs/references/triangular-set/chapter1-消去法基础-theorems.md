## §1.1 伪除法

> **原文位置**：§1.1, p.1–4

### 定义 1.1 — 伪余式与伪商

> **原文位置**：§1.1, p.2

设 $R$ 为整环，$f, g \in R[x]$，$\deg(f) = m \geq l = \deg(g) > 0$。

**伪除法**：存在 $q, r \in R[x]$ 使得

$$b_l^{m-l+1} \cdot f = q \cdot g + r$$

其中 $b_l = \text{lc}(g)$ 为 $g$ 的首项系数，$\deg(r) < l$ 或 $r = 0$。

| 符号 | 名称 |
|------|------|
| $r = \text{prem}(f, g, x)$ 或 $\text{prem}(f, g)$ | 伪余式（pseudo-remainder）|
| $q = \text{pquo}(f, g, x)$ 或 $\text{pquo}(f, g)$ | 伪商（pseudo-quotient）|

该公式称为**伪余式公式**。

**注**：若 $R$ 是域（或 $b_l$ 可逆），伪除法退化为普通欧几里得除法。

---

### 定义 1.2 — 行列式多项式

> **原文位置**：§1.1, p.3

设 $M = (m_{ij})_{t \times s}$ 为 $R$ 上的矩阵，$t \leq s$。**行列式多项式**定义为

$$\text{detpol}(M) = \det(M^{(t)}) x^{s-t} + \det(M^{(t+1)}) x^{s-t-1} + \cdots + \det(M^{(s)})$$

其中 $M^{(j)}$ 是由 $M$ 的前 $t-1$ 行和第 $j$ 列构成的 $t \times t$ 子矩阵。

对多项式有限序列 $A_1, \ldots, A_k$，$\max(\deg(A_i)) = t-1$，设 $\text{mat}(A_1, \ldots, A_k)$ 为其系数矩阵。则：

$$\text{detpol}(A_1, \ldots, A_k) = \text{detpol}(\text{mat}(A_1, \ldots, A_k))$$

---

### 命题 1.1 — 伪余式的显式表达

> **原文位置**：§1.1, p.4

设 $f, g \in R[x]$，$\deg(f) = m \geq l = \deg(g) > 0$。则：

$$\text{detpol}(x^{m-l}g, x^{m-l-1}g, \ldots, xg, g, f) = \text{prem}(f, g, x)$$

## §1.2 结式

> **原文位置**：§1.2, p.4–8

### 定义 1.3 — Sylvester 结式

> **原文位置**：§1.2, p.5

设
$$f = a_0 x^m + a_1 x^{m-1} + \cdots + a_m, \quad g = b_0 x^l + b_1 x^{l-1} + \cdots + b_l$$

为 $R[x]$ 中的正次数多项式。**Sylvester 矩阵** $S$ 为 $(m+l) \times (m+l)$ 矩阵：

```
S = [ a₀ a₁ ... aₘ                     ]   (l 行)
    [    a₀ a₁ ... aₘ                  ]
    [       ...                        ]
    [          a₀ a₁ ... aₘ            ]
    [ b₀ b₁ ... bₗ                     ]   (m 行)
    [    b₀ b₁ ... bₗ                  ]
    [       ...                        ]
    [          b₀ b₁ ... bₗ            ]
```

$f$ 和 $g$ 关于 $x$ 的 **Sylvester 结式**为：

$$\text{res}(f, g, x) = \det(S)$$

**扩展定义**（特殊情况）：

$$\text{res}(f, g, x) = \begin{cases}
a_0^l, & \text{若 } f \in R, g \notin R, \\
b_0^m, & \text{若 } g \in R, f \notin R, \\
0, & \text{若 } f = g = 0, \\
1, & \text{若 } f, g \in R \text{ 不全为零}.
\end{cases}$$

---

### 引理 1.1 — 结式的 Bezout 型等式

> **原文位置**：§1.2, p.6

设 $f, g \in R[x]$ 为正次数多项式。存在非零多项式 $p, q \in R[x]$ 使得：

$$pf + qg = \text{res}(f, g, x)$$

其中 $\deg(p, x) < \deg(g, x)$，$\deg(q, x) < \deg(f, x)$。

---

### 定理 1.1 — 结式与公因子

> **原文位置**：§1.2, p.7

设 $f, g \in R[x]$ 为上述形式的正次数多项式，$a_0$ 和 $b_0$ 不同时为零。则 $f$ 和 $g$ 有非常数公因子 **当且仅当** $\text{res}(f, g, x) = 0$。

---

### 命题 1.2 — 结式的性质

> **原文位置**：§1.2, p.7

设 $f, g$ 如上。结式满足：

1. 若 $f \in R$ 或/且 $g \in R$，$\text{res}(f, g, x)$ 满足扩充定义；
2. $\text{res}(f, g, x) = (-1)^{ml} \text{res}(g, f, x)$；
3. 设 $l \geq m > 0$，$r = \text{rem}(g, f)$ 为 $R$ 的商域中的余式。令 $t = \deg(r, x)$。则：
   $$\text{res}(f, g, x) = a_0^{l-t} \text{res}(f, r, x)$$

这三条性质给出了计算结式的自然算法。

---

### 引理 1.2 — 结式的唯一性

> **原文位置**：§1.2, p.7

设 $f, g \in R[x]$。若 $R(f, g, x)$ 是 $f, g$ 系数上的多项式（在某扩域上），且满足命题 1.2 的三条性质，则 $R(f, g, x) = \text{res}(f, g, x)$。

---

### 定理 1.2 — 结式的根表示

> **原文位置**：§1.2, p.8

设 $f, g$ 如上，$\alpha_i$ ($i = 1, \ldots, m$) 和 $\beta_j$ ($j = 1, \ldots, l$) 分别为 $f$ 和 $g$ 在某扩域中的根。则：

$$\text{res}(f, g, x) = a_0^l \prod_{i=1}^m g(\alpha_i) = (-1)^{ml} b_0^m \prod_{j=1}^l f(\beta_j) = a_0^l b_0^m \prod_{i=1}^m \prod_{j=1}^l (\alpha_i - \beta_j)$$

---

### 推论 1.1 — 判别式

> **原文位置**：§1.2, p.8

$f$ 的**判别式**为：

$$\text{dis}(f, x) = a_0^{2m-2} \prod_{1 \leq j < i \leq m} (\alpha_i - \alpha_j)^2$$

则：

$$\text{res}(f, f', x) = (-1)^{\frac{m(m-1)}{2}} a_0 \, \text{dis}(f, x)$$

---

## §1.3 子结式

> **原文位置**：§1.3, p.8–18

### 定义 1.4 — j-次子结式与 PSC

> **原文位置**：§1.3, p.8

设 $f, g \in R[x]$ 如 (1.4) 所示，$m = \deg(f) \geq \deg(g) = l > 0$。

对每个 $j$ ($0 \leq j < l$)，定义：

$$S^j = \text{mat}(x^{l-j-1}f, \ldots, xf, f, x^{m-j-1}g, \ldots, xg, g)$$

这是 $(m+l-2j) \times (m+l-j)$ 矩阵。

$f$ 和 $g$ 关于 $x$ 的 **$j$-次子结式**为：

$$S_j = \text{subres}_j(f, g) = \text{detpol}(S^j) = \sum_{i=0}^j \det(S^{j(m+l-2j+i)}) x^{j-i}$$

**$j$-次主子结式系数 (PSC)** 为：

$$R_j = \det(S^{j(m+l-2j)})$$

**扩展定义**（当 $m > l+1$ 时）：
- $S_l = b_0^{m-l-1} g$, $R_l = b_0^{m-l}$
- $S_j = R_j = 0$ for $l < j < m-1$

**性质**：
- $\deg(S_j, x) \leq j$
- $S_j$ 称为**退化的**（defective of degree $t$），若 $\deg(S_j, x) = t < j$
- $S_j$ 称为**正则的**（regular），若 $\deg(S_j, x) = j$
- $S_0 = R_0 = \text{res}(f, g, x)$

---

### 定理 1.3 — 子结式的 Bezout 型等式

> **原文位置**：§1.3, p.9

设 $f, g \in R[x]$，$m = \deg(f) \geq \deg(g) = l > 0$。对 $j$-次子结式 $S_j$ ($0 \leq j < m-1$)，存在多项式 $p_j, q_j \in R[x]$ 使得：

$$p_j f + q_j g = S_j$$

其中 $\deg(p_j, x) < l-j$，$\deg(q_j, x) < m-j$。

---

### 命题 1.3 — 子结式与伪余式的关系

> **原文位置**：§1.3, p.9

设 $f, g \in R[x]$，$m = \deg(f) \geq \deg(g) = l > 0$。则：

$$S_{l-1} = (-1)^{m-l+1} \text{prem}(f, g, x)$$

---

## §1.3.1 Habicht 定理

> **原文位置**：§1.3.1, p.10–13

### 定义 1.5 — 子结式链与 PSC 链

> **原文位置**：§1.3.1, p.10

设 $f, g \in R[x]$，$m = \deg(f) \geq \deg(g) = l > 0$。定义：

$$\mu = \begin{cases} m-1, & \text{若 } m > l, \\ l, & \text{否则}. \end{cases}$$

令 $S_{\mu+1} = f$，$S_\mu = g$，$S_j$ ($0 \leq j < \mu$) 为第 $j$ 次子结式。

$f$ 和 $g$ 关于 $x$ 的 **子结式链**为：

$$S_{\mu+1}, S_\mu, S_{\mu-1}, \ldots, S_0$$

若每个 $S_j$ 都正则，则称链**正则**（regular）；否则称**退化**（defective）。

令 $R_{\mu+1} = 1$，对 $0 \leq j \leq \mu$：

$$R_j = \begin{cases} \text{lc}(S_j, x), & \text{若 } S_j \text{ 正则}, \\ 0, & \text{否则}. \end{cases}$$

序列 $R_{\mu+1}, R_\mu, \ldots, R_0$ 称为 **PSC 链**。

---

### 引理 1.3 — 符号系数情形

> **原文位置**：§1.3.1, p.10

设 $A = a_0 x^{n+1} + \cdots + a_{n+1}$，$B = b_0 x^n + \cdots + b_n$ 为 $\mathbb{Z}[a_0, \ldots, a_{n+1}, b_0, \ldots, b_n][x]$ 中的多项式。

则：
- (a) $S_{n-1}(A, B) = \text{prem}(A, B, x)$
- (b) 对 $i < n-1$：$b_0^{2(n-i-1)} \text{subres}_i(A, B) = \text{subres}_i(B, \text{prem}(A, B, x))$

---

### 定理 1.4 — Habicht 定理

> **原文位置**：§1.3.1, p.11

设 $A, B$ 如上，$S_{n+1}, S_n, \ldots, S_0$ 为子结式链，$R_{n+1}, \ldots, R_0$ 为 PSC 链。

则对每个 $j = 1, \ldots, n$：

**(a)** $R_{j+1}^2 S_{j-1} = \text{prem}(S_{j+1}, S_j, x)$

**(b)** $R_{j+1}^{2(j-i)} S_i = \text{subres}_i(S_{j+1}, S_j)$ for $0 \leq i < j$

**证明**：对 $j$ 归纳。$j=n$ 时由引理 1.3 得证。

---

### 命题 1.4 — 环同态下的子结式

> **原文位置**：§1.3.1, p.12

设 $\phi: R \to \tilde{R}$ 为环同态，$\phi: R[x] \to \tilde{R}[x]$ 为其诱导同态。设 $f, g$ 如 (1.4) 所示，$\tilde{m} = \deg(\phi(f)) \geq \tilde{l} = \deg(\phi(g))$。

相应地定义 $\tilde{\mu}$。则对 $0 \leq j < \tilde{\mu}$：

$$\phi(S_j) = \delta \cdot \tilde{S}_j$$

其中 $\tilde{S}_j$ 为 $\phi(f)$ 和 $\phi(g)$ 的 $j$-次子结式，且：

$$\delta = \begin{cases}
1, & \text{若 } \tilde{a}_0 \tilde{b}_0 \neq 0, \\
\tilde{a}_0^{l-\tilde{l}}, & \text{若 } \tilde{a}_0 \neq 0, \tilde{b}_0 = 0, \\
(-1)^{(m-\tilde{m})(l-j)} \tilde{b}_0^{m-\tilde{m}}, & \text{若 } \tilde{a}_0 = 0, \tilde{b}_0 \neq 0, \\
0, & \text{若 } \tilde{a}_0 = \tilde{b}_0 = 0.
\end{cases}$$

> **这是第2章频繁引用的关键结果**（定理 2.4、引理 2.3 等）。

---

### 命题 1.5 — 退化子结式

> **原文位置**：§1.3.1, p.13

设 $\phi: \mathbb{Z}[a_0, \ldots, a_{n+1}, b_0, \ldots, b_n] \to \tilde{R}$ 为环同态。

若 $\phi(S_{j+1})$ 正则且 $\phi(S_j)$ 退化（次数为 $t$），则：

**(a)** $\phi(S_{j-1}) = \phi(S_{j-2}) = \cdots = \phi(S_{t+1}) = 0$

**(b)** 若 $j = n$：$\phi(S_t) = [\text{lc}(\phi(S_{n+1})) \cdot \text{lc}(\phi(S_n))]^{n-t} \phi(S_n)$
&nbsp;&nbsp;&nbsp;&nbsp;若 $j < n$：$\phi(R_{j+1})^{j-t} \phi(S_t) = \text{lc}(\phi(S_j))^{j-t} \phi(S_j)$

**(c)** 若 $j = n$：$\phi(S_{t-1}) = [-\text{lc}(\phi(S_{n+1}))]^{n-t} \text{prem}(\phi(S_{n+1}), \phi(S_n), x)$
&nbsp;&nbsp;&nbsp;&nbsp;若 $j < n$：$\phi(-R_{j+1})^{j-t+2} \phi(S_{t-1}) = \text{prem}(\phi(S_{j+1}), \phi(S_j), x)$

## §1.3.2 子结式链定理

> **原文位置**：§1.3.2, p.14–18

### 定理 1.5 — 子结式链 ($m > l$)

> **原文位置**：§1.3.2, p.14

设 $S_{\mu+1}, S_\mu, \ldots, S_0$ 为 $f = S_{\mu+1}$ 和 $g = S_\mu$（$m > l$）的子结式链，$R_{\mu+1}, R_\mu, \ldots, R_0$ 为其 PSC 系数。

若对某个 $j$ ($1 \leq j \leq \mu$)，$S_{j+1}$ 和 $S_j$ 都正则：

$$R_{j+1}^2 S_{j-1} = \text{prem}(S_{j+1}, S_j, x)$$

若 $S_{j+1}$ 正则但 $S_j$ 退化（次数 $t < j$）：

$$S_{j-1} = S_{j-2} = \cdots = S_{t+1} = 0$$
$$R_{j+1}^{j-t} S_t = \text{lc}(S_j)^{j-t} S_j$$
$$(-1)^{j-t} R_{j+1}^{j-t+2} S_{t-1} = \text{prem}(S_{j+1}, S_j, x)$$

---

### 定理 1.6 — 子结式链 ($m = l$)

> **原文位置**：§1.3.2, p.14

记号同上，但 $m = l$。

若 $S_\mu$ 和 $S_{\mu-1}$ 都正则：

$$R_\mu S_{\mu-2} = \text{prem}(S_\mu, S_{\mu-1}, x)$$

若 $S_\mu$ 正则但 $S_{\mu-1}$ 退化（次数 $t$）：

$$S_{\mu-2} = S_{\mu-3} = \cdots = S_{t+1} = 0$$
$$S_t = \text{lc}(S_{\mu-1})^{\mu-t-1} S_{\mu-1}$$
$$(-1)^{\mu-t+1} R_\mu S_{t-1} = \text{prem}(S_\mu, S_{\mu-1}, x)$$

若对某个 $j$ ($1 \leq j < \mu-1$)，$S_{j+1}$ 和 $S_j$ 都正则：

$$R_{j+1}^2 S_{j-1} = \text{prem}(S_{j+1}, S_j, x), \quad j < \mu-1$$

若 $S_{j+1}$ 正则但 $S_j$ 退化（次数 $t$）：

$$S_{j-1} = S_{j-2} = \cdots = S_{t+1} = 0$$
$$R_{j+1}^{j-t} S_t = \text{lc}(S_j)^{j-t} S_j$$
$$(-1)^{j-t} R_{j+1}^{j-t+2} S_{t-1} = \text{prem}(S_{j+1}, S_j, x), \quad j < \mu-1$$

> **注**：$j < \mu-1$ 时的关系式对 $j = \mu-1$ **不成立**。

## §1.3.3 子结式多项式余式序列

> **原文位置**：§1.3.3, p.18–21

### 定义 1.6 — 正则子结式链

> **原文位置**：§1.3.3, p.18

设 $f, g$ 如上，$m = \deg(f) \geq \deg(g) = l > 0$。

$f$ 和 $g$ 的 **正则子结式链**是子结式链的子序列，包含所有正则子结式及最后一个非零退化子结式（若存在）。

---

### 定义 1.7 — 块索引与正则子链

> **原文位置**：§1.3.3, p.20

设 $S: S_{\mu+1}, S_\mu, \ldots, S_0$ 为 $f$ 和 $g$ 的子结式链。

严格递减的非负整数序列 $d_1, d_2, \ldots, d_t$ 称为 $S$ 的 **块索引**（block indices），若：
- $d_1 = \mu + 1$
- 对 $2 \leq i \leq t$，$S_{d_i}$ 正则
- 对 $0 \leq j \leq \mu$ 且 $j \notin \{d_2, \ldots, d_t\}$，$S_j$ 退化

序列 $S_{d_2}, \ldots, S_{d_t}$ 称为 **子结式正则子链**。

**块结构**：第 $i$ 个非零块形如：

$$S_{d_{i-1}-1}, 0, \ldots, 0, S_{d_i}$$

其中 $S_{d_{i-1}-1} \sim S_{d_i}$（同次数）且 $d_{i-1} - 1 \geq d_i$。

---

### 命题 1.6 — 块结构关系

> **原文位置**：§1.3.3, p.20–21

设 $f, g$ 如 (1.4) 所示，$m \geq l > 0$。设 $S$ 为子结式链，$d_1, \ldots, d_t$ 为块索引。

**(a)** 若 $m > l$，对 $i = 1, \ldots, t-1$：

$$R_{d_{i+1}}^{\delta_{i+1}-2} S_{d_i-1} = \text{lc}(S_{d_i-1}, x)^{\delta_{i+1}-2} S_{d_i-1}$$

$$(-R_{d_i})^{\delta_{i+1}} S_{d_{i+1}-1} = \text{prem}(S_{d_i}, S_{d_i-1}, x)$$

其中 $\delta_{i+1} = d_i - d_{i+1} + 1$。

**(b)** 若 $m = l$，类似关系成立，但初始条件需调整。
