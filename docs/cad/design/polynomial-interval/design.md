# 多项式区间求值设计

## 范围与调研

本模块把 ZZ/QQ 多项式及 QQ 闭盒映射为一个 `rational_interval`，独立于三角列、实代数点与 CAD。不增加数据容器，不实现区间系数多项式环，不改动现有 `assign`。

仓库的 `polynomial.hh::assign` 是代入接口，目前按项求幂并累加；`lex_<var_order>` 按变量优先级、指数降序存储项；`poly_convert` 可以重排多项式。基础区间层已经提供精确 QQ 加法、乘法与非负整数幂，可以直接复用。

[Maple 的 Horner 接口](https://www.maplesoft.com/support/help/Maple/view.aspx?path=convert%2Fhorner) 按指定变量顺序递归处理系数。本模块采用这一组织方式，但以下稀疏区间算法、存储适配和证明由本设计明确给出；不把 Maple 的标量求值正确性当作区间算法的证明。

| 方案 | 成本与性质 | 决策 |
|---|---|---|
| 逐项求幂、相乘、累加 | 简单，但公共前缀重复计算；原实现每个变量还线性搜索盒 | 用作性能对照 |
| 逐项求值加幂缓存 | 保持原包络，但不能合并公共前缀，增加缓存及查找 | 不引入 |
| 字典序稀疏多元 Horner | 连续项分组，共享变量前缀；仅计算实际指数间隙 | 采用 |
| 搜索最优变量顺序、持久化表达式树 | 可能降低算术量，但增加策略与所有权接口 | 不在本模块范围 |

## 接口与架构

```cpp
template<class Tc, class To>
rational_interval assign_interval(
    const polynomial_<Tc, To>& f,
    const std::vector<variable>& vars,
    const std::vector<rational_interval>& box);
```

命名沿用仓库 `assign` 的代入语义，后缀明确结果是区间包络。支持的系数为 ZZ、QQ。输入须是按自身比较器规范化的普通多项式，比较器须满足库的单项式序约定；调用过程中不修改它及其比较器。直接修改内部存储而破坏排序、合并同类项等不变量的对象不在契约内。

一般入口不要求输入多项式采用字典序；字典序是递归内核所用的存储顺序。Horner 本身可以用于其他输入序，但本实现直接在项数组上划分连续系数组，需要先转换为字典序。例如变量优先级为 x、y 时，`x*y^3 + x^2 + x*y` 按分级字典序排列的 x 指数依次为 1、2、1，同一指数的项不连续；转为字典序后依次为 2、1、1，才能直接分组并按递减指数计算。该转换由 `assign_interval` 完成，调用者不必预先转换。

`vars[i]` 绑定 `box[i]`，同时指定 Horner 的变量优先顺序（`vars[0]` 最先处理）。公共入口要求变量无重复、尺寸一致、覆盖多项式变量，允许额外变量；违反时抛 `std::invalid_argument`，零多项式也检查变量表。

参照 `cad.hh` 中 `__project/project` 和 `__open_cad/open_cad` 的两层结构：

```cpp
template<class Tc, class VarOrder>
rational_interval __assign_interval(
    const polynomial_<Tc, lex_<VarOrder>>& f,
    const std::vector<variable>& vars,
    const std::vector<rational_interval>& box);
```

1. 字典序核心 `__assign_interval`：调用者保证 vars 严格按 `f.comp()` 排列、无重复、覆盖 f 的变量、尺寸匹配且指数非负。多项式的规范化和非负指数由调用者保证，本层不重复验证。Debug 仅断言尺寸、变量顺序和访问下标；Release 不重复验证。直接读取原项数组与盒，没有绑定映射、排序或多项式复制。普通 lex 是该模板的特例。
2. 一般入口 `assign_interval`：运行时检查后构造 `lex_<custom_var_order>(vars)`，用 `poly_convert` 转换，再调用核心。包括普通 lex 在内的任意输入序均走这条明确路径；知道自身已满足字典序契约的调用方直接调用核心。

保留 vars 是为了同时支持普通 lex、自定义变量序及缺少某些变量的系数多项式。比较器不具有统一的变量枚举接口，不能仅凭多项式出现的变量推断盒的坐标。三角列已有字典序可直接复用，但其变量及根盒按提升顺序保存；调用核心前须将两者一起改为比较器顺序，不能只反转其中一个。实点层将提升序变量和盒同步反转后调用字典序核心，见[实点设计](../modular-cad/real-algebraic.md)。

比较器与转换后的多项式是局部对象，返回值只拥有 QQ 端点。核心以变量下标定位盒，不保存借用指针。

## assign_interval 与 __assign_interval：一般入口与字典序入口

```text
assign_interval(f, vars, box):
  要求 vars.size = box.size，否则抛 invalid_argument
  order := lex_<custom_var_order>(vars)
  若 order.comp.v_map.size != vars.size，抛 invalid_argument（变量重复）
  对 get_variables(f) 返回的每个 (v,degree):
    若 v 不在 order.comp.v_map 中，抛 invalid_argument（缺少坐标）
  g := poly_convert(f, order)
  返回 __assign_interval(g, vars, box)

__assign_interval(f, vars, box):
  assert 尺寸匹配，vars 严格按 f.comp() 排序
  若 f 为空，返回 [0,0]
  返回 H(f.begin, f.end, 0, 0, vars, box)
```

## PI-HORNER：字典序稀疏内核

输入为非空连续项段 `[b,e)`，每项已经消去相同的前 `d` 个变量-指数对，剩余后缀仍按字典序排列。`d` 是单项式数组的偏移，不是变量表下标。初始 `d=0`；另外传递变量表中的搜索起点 h，初始 h=0。零多项式由调用层直接返回 `[0,0]`。

```text
H(b,e,d,h,vars,box):
  若 b 的单项式长度等于 d:
    返回 [b.coeff,b.coeff]                 // 此时段中只有常数项
  v := b.monomial[d].variable
  i := 从 h 开始向后找到 vars[i]=v 的下标
  DEG(t) := 若 t 的第 d 个变量是 v 则取其指数，否则为 0
  p := b
  first := true
  当 p != e:
    k := DEG(p)
    q := p 后第一个 DEG 不等于 k 的位置，或 e
    C := H(p,q,d+1,i+1,vars,box) 若 k>0
         否则 H(p,q,d,i+1,vars,box)
    若 first: R := C; first := false
    否则: R := R * pow(box[i], previous-k) + C
    previous := k
    p := q
  若 previous > 0: R := R * pow(box[i],previous)
  返回 R
```

零指数组中 v 已经缺席，不能把 d 加一，否则会丢弃下一个变量。两种分组的剩余变量均位于 v 之后，因此搜索起点都前进到 i+1；严格排序和覆盖前提保证查找不会越界。分组只用迭代器，不复制系数多项式，不创建按最高次数分配的数组。`pow` 调用区间层的整次幂，不能将偶次幂随意替换成多次区间乘法。例如 `[-1,1]^2=[0,1]`。

## 正确性与形式化证明义务

**分组引理。** 在共享前缀的字典序项段中，第一个剩余变量 v 具有最高优先级；v 的各正指数组连续且严格递减，缺席 v 的项构成最后的零指数组。正指数组消去一个共同变量对后、零指数组保持偏移后，均满足递归前提。若首项后缀为空，则没有其他后缀：否则非空后缀必排在它之前；规范化排除了重复常数。

**代数恒等式。** 设各组为 `C0*v^k0,...,Cm*v^km`，其中 `k0>...>km>=0`。循环处理到 j 时，标量表达式为 `sum(i=0..j, Ci*v^(ki-kj))`。初始为 C0；乘以 `v^(kj-k(j+1))` 再加下组保持不变量。最后乘 `v^km` 即为原多项式。

**包含性。** 对递归结构归纳：常量返回单点；递归系数包络包含每个盒内点的系数值。由区间幂、乘法、加法的包含性，将上一段标量不变量提升为区间包含不变量，最终得到 `f(a) ∈ assign_interval(f,B)`，对所有 `a ∈ B` 成立。

**单调性。** 固定多项式及其变量比较序，分组与控制流不依赖盒端点。每个区间原语对包含关系单调，结构归纳得 `B' ⊆ B ⇒ H(f,B') ⊆ H(f,B)`。

**点精确与收敛。** 单点输入使每个原语退化为精确 QQ 运算。对于围绕固定实点且各坐标宽度趋零的盒序列，其端点趋于该实点；有限表达式中的加、乘、非负整数幂端点函数连续，递归得到输出两端点均趋于 f(a)，宽度趋零。不要求实点可在库中直接表示。此性质足以供后续系数包络使用，上层求根算法另见实点设计。

**终止性。** 可用“项段中剩余变量对总数，项数”的字典序作递归度量：正指数组消去至少一个对，零指数组丢弃非空的正指数组，均严格下降；循环 p 前进到 q。指数非负且严格递减，因此差值 `previous-k` 不会发生有符号溢出。

**机器精化义务。** 将规范化项数组解释为有限映射，证明字典序分组引理、`poly_convert` 的值保持及目标序规范化、迭代器范围与 d 边界、QQ 转换精确性、变量表/盒的下标对应与局部比较器存活，再将区间层原语规格组合到上述不变量。这里提供数学证明与实施契约，尚未提供机器检查证明。

## 包络与性能边界

Horner 不承诺和逐项求值返回同一包络，也不承诺更窄。例如 `x²+x` 在 `[-1,1]` 上，逐项得到 `[-1,2]`，Horner 得到 `[-2,2]`；`x²-2x+1` 在 `[1,2]` 上，逐项得到 `[-2,3]`，Horner 得到 `[-1,1]`。改变变量优先次序也可能改变包络，但不改变上述四个正确性性质。调用方不能把“包含零”等同于“值等于零”。

设项数为 n，盒变量数为 m，实际变量数为 r。公共入口复用 `get_variables(f)` 提取变量，其成本由仓库既有实现决定；构造目标变量序为 `O(m log(m+1))`，覆盖检查为 `O(r log(m+1))`，无需另建变量集合；字典序核心的递归分组及变量表扫描最坏 `O(nm)`；没有每项的映射构造或查询。递归深度不超过实际变量数加一，额外存储为递归局部区间（不计大整数位成本）。Debug 核心额外进行断言校验。公共入口还需复制与排序（比较成本取决于单项式长度）；QQ 位复杂度和区间宽度可能主导总耗时。仅在存在公共前缀时预期减少重复算术，不声称所有输入更快。

## 伪代码与实现对应

| 设计步骤 | 实现 | 实现性质 |
|---|---|---|
| `assign_interval` 坐标检查 | `assign_interval` 开头 | 尺寸、重复和变量覆盖在 Release 检查；复用目标序的映射与 get_variables，不逐项检查多项式合法性 |
| `assign_interval` 转换 | `assign_interval` 后半 | 以 vars 构造 `lex_<custom_var_order>`，转换后调用核心；输入序不决定输出的 Horner 变量顺序 |
| 字典序入口 | `__assign_interval` | 用 assert 检查变量表严格匹配比较器、尺寸及内核访问下标；Release 不构建集合或映射，不复制多项式；普通 lex 也可直接调用 |
| PI-HORNER 常量与选变量 | `__assign_interval_horner` 开头 | 常量后缀只含一项；首项决定变量；从 var_begin 前进到相应变量下标，直接访问 box |
| 连续指数组 | `exponent` 与 `group/end` | 正指数降序，缺席变量的零次组在末尾；每次迭代推进到下一组 |
| 系数递归 | `offset + (degree > 0 ? 1 : 0)` 和 `index + 1` | 仅实际存在变量对时增加单项式偏移；正次组和零次组的变量搜索起点均越过本层变量 |
| 稀疏 Horner 更新 | `previous-degree`、末尾 `previous` | 初始化用第一个系数；指数间隙用区间 pow；末尾补上最低指数因子 |
| 生命周期 | 局部比较器与转换后多项式 | 比较器在计算期间存活；核心只借用数组，返回值拥有 QQ 端点 |


内核没有构造稠密系数数组，也没有把区间当作系数域运行多项式归一化。控制流只依赖固定多项式，不依赖端点，所以设计中的单调性与收敛证明适用。分组与变量表扫描以盒变量数 m 给出 O(nm) 上界；不会按最高次数分配稠密存储。

## 性能实测

环境：arm64，Homebrew GCC 13.4.0，求值基准翻译单元 `-O2 -DNDEBUG`，链接既有 Debug 静态库。对照为替换前的逐项区间算法，逐项对照包含其原有输入检查；字典序核心按调用者保证前置条件测量，Release 关闭断言校验；一般入口包含运行时检查和每次转换。两路径的接口成本不同，此处评估实际调用方式。多项式构造不计时。结果符号写入 volatile 防止消除调用。三个独立运行，不以测试断言规定性能。

## 随机多项式对照实验

固定种子 `20261015`，分别生成 ZZ、QQ 系数的随机多项式。每种系数使用四组规模，每组 100 个，共 800 个。各项的指数向量均匀随机生成、去重，保证项数准确；每个变量的指数上界分别为 6、4、4、8（不是总次数上界）。非零系数的分子取 -9 到 9，QQ 分母取 1 到 9。每个坐标的中点取 k/4（k 为 -8 到 8），半径取 r/4（r 为 1 到 4），因此盒中包含正、负及跨零区间。

对照方法直接按原 assign 的算术流程逐项计算 `系数 × 各变量区间的幂`，最后累加；同样使用本库 rational_interval，不经过浮点运算。它使用预先建立的变量映射，未添加幂缓存，也不构造输出多项式。这里比较的是两种区间求值算法的耗时，不是原 assign 返回多项式的完整函数耗时。

正确性观察：

- 800 个单点区间输入，Horner 与逐项结果全部相等；另用仓库原 `assign` 计算 QQ 精确点值，也全部相等。
- 800 个非单点盒，Horner 与逐项的区间端点均不完全相同。这是这组随机输入的结果，不是所有输入的普遍规律。
- 其中 651 个 Horner 包络为逐项包络的真子集，32 个为真超集，117 个相互不包含。
- 每个盒检查下端角点、上端角点、中点和一个混合角点，共 3200 次。用原 `assign` 计算的精确点值全部包含于两种包络。有限抽样不代替包含性证明。
- 每个非单点盒上，一般入口的结果都与同一目标变量序的字典序核心相等。

性能环境与前节一致：GCC 13.4.0，arm64，测试翻译单元 `-O2 -DNDEBUG`，链接既有 Debug 静态库。每组预热后测五批，轮换算法顺序，取五批耗时的中位数。表中时间是计算整组 100 个多项式的毫秒数，随机生成、归一化、正确性校验和预先建立的绑定映射均不计时。字典序核心的输入提前转换；一般入口每次从 grlex 输入检查并转换，计入耗时。
