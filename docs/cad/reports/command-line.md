## 复核结论

三段式 TXT 解释为存在实数赋值的 CNF。所有系数由 ZZ／QQ 精确构造；指数、变量、分母和原子引用在读取边界检查，非法输入不会进入 CAD。表达式求值按语法结构归纳保持原式的 QQ 多项式值；常量除法的非零条件单独检查。CNF 判断只解释完整 CAD 的原输入符号行。SAT 取一个满足叶的认证样本，UNSAT 要求全部叶均不满足，依据原完整 CAD 的覆盖与符号不变契约。

公式和扫描状态类型只保存数据，语法、布尔判断和 CLI 调度是自由函数。求解继续使用有检查和换序的 `full_cad`，没有从 CLI 直接调用字典序内部内核。样本在结果对象存活时打印，按其自身坐标顺序输出，避免比较器悬空或顺序混淆。错误写入标准错误，正常答案与错误退出码区分。

样本测试最初要求定义链必须含原式 `x²-2`，实际 CAD 选择了乘积方程 `x³-2x`。该预期过强：乘积与 `(5/4,3/2)` 共同唯一指定正根 √2。测试已改为检查证书结构和严格包络关系，并检查反序下双变量的坐标映射；没有为此修改求解算法。
