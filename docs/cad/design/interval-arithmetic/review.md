# 区间层实现审核

对照 [I01–I13 规格及证明](design.md)。

| 规格 | 实现 | 结论 |
|---|---|---|
| I01 不变式 | `rational_interval` 构造 | 按值接收并移动端点；对成员检查倒置端点，release 仍有效 |
| I02–I04 四则 | 隐藏友元 `+,-,*` | 加减对应端点公式；乘法对应 I04 九类符号细化 |
| I05–I06 除法 | `reciprocal`, `/`, `/=` | 含零拒绝；先计算后赋值，自别名正确 |
| I07 幂 | `pow` | 负指数、零次、一次、单点与一般奇偶分支对应 I07 |
| I08–I10 集合关系 | `contains`, `interior_contains`, `overlaps`, `intersection`, `hull` | 闭区间端点语义；空交集独立表示 |
| I11 几何操作 | `width`, `midpoint`, `bisect` | 不擅自选择含根的一半 |
| I12 符号 | `sign`, `sgn`, `contains_zero` | 读取分子符号；包含零与恒等于零分开 |
| I13 相等 | `==`, `!=` | 端点相等，无虚假的区间全序 |

公共入口只依赖 `number/QQ.hh` 与标准库。QQ/ZZ 的现有底层依赖包括 GMP 和 Boost 的哈希头；区间模块不依赖 MPRIA。

独立编译测试可只链接 GMP，无需链接 libclpoly。用例按接口分组，直接比较明确的期望值，覆盖超过机器字长的端点、四则、包含性、幂、非法输入和复合赋值异常不修改原值。构建方式与实测结果集中于[验证报告](../../reports/modular-cad.md)。

数学证明仍是人工证明，未宣称机器形式化验证。后续层独立承担多项式估值包含性和保根证书的正确性。

## 验证证据

区间测试按接口列出九种乘法符号组合、两个跨零区间极值的不同选择、零端点、零区间、自别名、符号及单点幂的明确期望。每项断言直接比较输入运算结果和手写期望值；不包含 GMP 参考计算、嵌套枚举或动态生成的期望值。

Debug、`-O2 -DNDEBUG` 和独立 Clang ASan/UBSan 的区间测试均通过 94 项断言。受影响的三角列、多项式估值、实代数点、Lazard 和完整 CAD 回归通过。该 sanitizer 结果仅覆盖区间测试，不覆盖整库。

局部微基准采用 GCC 13、`-O2 -DNDEBUG`，64 个输入，每轮 12,800 次运算，交替执行被比较实现，三轮取中位数。小端点为小分数，大端点的分子分母约 256 位；计时外检查结果端点一致。在没有并发构建的测量中，非负乘法约快 2.24–2.46 倍，双方跨零乘法约快 1.15–1.20 倍；单点五次幂约快 1.98–2.59 倍。普通非单点五次幂的小端点测量有波动，不宣称所有输入均加速。这些数据不是整个 CAD 的性能保证。

区间测试日志位于 `/tmp/clpoly-interval-readable-*.log`；上层回归日志位于 `/tmp/clpoly-interval-optimized-*.log`；微基准源码为 `/tmp/clpoly-interval-optimized-bench.cc`，参考头快照为 `/tmp/clpoly-interval-before.hh`，测量日志为 `/tmp/clpoly-interval-optimized-bench-repeat.log`。临时文件可能由系统清理；实现依据是上述运算成本与等价证明，测量仅提供局部证据。
