# 后续形式化验证：模块证明接口

2026-10-22。当前是 C++ 实现、人工数学证明和测试，不是机器验证结果。

## 表示关系

1. `QQRep(q,r)`：两个 ZZ 表示分母正、既约的有理数 r；算术实现保持其语义。
2. `IntervalRep(I,[a,b])`：a≤b 的非空闭区间；可表达有界区间；不存在隐式 NaN/无穷/空区间。
3. `ChainRep(T,vars)`：vars 采用提升顺序，与 CAD 对外的投影顺序相反；外部比较器的末尾连续变量按 reverse(vars) 排列，第 i 方程的主变量是 vars[i]，也是该方程在比较器下最小的变量。方程只含提升前缀变量、关于主变量正次数，各初式在前缀所有复零点上非零。`Squarefree(T)` 另要求所有判别式不消失。
4. `PointRep(A,alpha)`：正则平方自由链及严格有理隔离盒；每前缀唯一根；每层有理平移后的根盒位于正半轴，两界端点异号、导数同号证书成立。
5. `Representative(p,A,i)`：数据 p∈QQ[x,y]，数学含义 E_i(p)；这一关系不对应无理系数运行时对象。
6. `TreeRep(D)`：层变量、父子 CSR、合并根表、每节点样本和维数一致；来源根身份 `(p,r)` 与第 p 个 Lazard 求值的第 r 个不同根对应，共享根对所有来源计数。

## 模块定理与依赖

| 层 | 必证结论 | 终止性/依赖 |
|---|---|---|
| QQ/区间 | 精确端点及包含性；有定义操作的包含单调性 | 整数算法、有限端点计算 |
| QQ 开区间采样 | 严格包含；既约分母最小，其次分子绝对值最小 | 连分数区间双射，分子分母同时最小的归纳，有限端点分母和下降 |
| 多项式估值 | 包含真实像；嵌套；点收敛时宽度→0 | 对固定表达式结构归纳 |
| 三角列分解 | WRSD 覆盖和标签；平方自由分解保持零集 | XY16 度数/层数递归措施及其 C++ 对应 |
| 实点隔离 | 每个根且仅一个根；无漏根；证书保持 | XZ06 简单根稳定性、UNI、严格 Cauchy 根界 |
| NSHR/REFINE | 保根、嵌套、任意精度终止 | 第一维收缩；高维 δ_n+w_n/4 递推 |
| 点判零 | 真当且仅当 c(alpha)=0 | 有限分支覆盖；错误分支最终区间排除 |
| 点符号 | 正确且终止 | 判零后非零与区间收敛 |
| Lazard | 返回 lex 最小 Taylor 系数及 valuation | 前缀不变量、导数与前缀求值交换、次数界 |
| 纤维根 | 所选前缀下全部互异根 | 先消除恒零/降次分支、平方自由化，仅重编码和提升所选前缀；去重及持久化区间分离 |
| CAD | 覆盖、互不相交、柱形性、符号不变 | 正确投影和 delineability 定理 + 每父完整栈 |

## CAD 目标定理

输入有限 A⊂QQ[x1,...,xn]，输出 D 是 R^n 的有限柱状代数分解；每叶 C 非空、连通且半代数，各叶互不相交并覆盖 R^n；每个样本在其胞腔中；对所有 f∈A，f 在每叶上符号恒定且等于记录值。样本精确运算只证明点上的符号，不能替代整胞腔的 delineability 证明。

## C++ 精化义务

变量序转换与比较器共享生命周期；零多项式/空链处理；clear-denominator 仅保持零集而非原数值；例外路径不伪造证书；有限数组/次数索引；GMP 底层语义；根候选排序的严格弱序和自比较；私有隔离盒防止外部绕过不变式；前缀证书复用及内部单层组合必须保持已验证的 ChainRep/PointRep，公开构造仍验证外部输入。

三角列只保存外部比较器地址，默认复制／移动保持该地址与所有方程的比较器地址一致；前缀和分解分支也借用它。调用者须保证比较器比全部借用者活得更久，且期间不改变变量序。`convert` 和 `integer_equations` 的结果不依赖原链继续存活。CAD 结果容器持有稳定比较器，其样本副本的使用也受此生命周期约束。投影变量表、反向提升坐标、根盒和比较器之间的下标对应须分别陈述，不能将同名的 `vars` 视为同一种顺序。

前缀缓存须证明：累计平方自由标记等价于该前缀全部判别式条件，截取方程保持正则性。内部单层提升组合已认证前缀与新层证书，保持公开构造的同一 PointRep。REENCODE 的递归度量为维数；ROOTS-QQ 须证明过滤分支不丢失指定纤维、精确去重保持根集、持久化精化最终使不同根严格分离。

三角列公开入口须证明：变量检查与序转换建立 `__weak_split_zero` 的前提，转换保持 QQ 多项式值。内部入口仅有断言，证明不能依赖断言在 Release 中执行；必须由调用处建立序一致、变量覆盖和有效 ChainRep。`__make_regular_chain` 的正则性来自 XY16 输出契约，累计平方自由属性来自判别式计算；`squarefree_decomposition` 的全 true 标记来自 Algorithm 3.1。对象装配和前缀截取须在不重复公开构造检查的情况下保持 ChainRep、方程按值保存和外部比较器借用约定。

来源计数须证明：处理第 j 个合并根前，count[p] 等于此前属于来源 p 的不同根数；推进所有来源保持不变量，规范身份及其查询均返回同一根证书。点查询及解析根身份即使精化内部证书，仍保持选定点值。

采样须证明：缺失端点只表示无穷，不进入 QQ 运算；有限端点相等时拒绝；非负连分数循环保持区间经已存逆变换映射回原区间，恢复时除数均正。终止度量为两有限端点的既约分母之和，整数下界转为无界基本分支；恢复归纳同时控制正分子与分母。C++ 的 `vector<ZZ>` 逆序恢复须精化该复合映射。CAD 另证明根盒 QQ 内间隙包含于真实根间隙，不能将 QQ 内间隙的最简性误写为整个代数 Sector 的最简性。完整伪代码与人工证明见[采样设计](../rational-sampling.md)和 PDF 的 SAMPLE-RATIONAL。

最终机器证明需分别导入或证明 XY16 分解、XZ06 隔离论证、投影与 delineability。当前 PDF 对新增算法给出了人工正确性与终止性证明，未声称已形式化这些依赖。

三角列分支只导入 WRSD 的两类零集等式，点判零不得额外假设零分支的伪余式为零。RSD 不作为当前证明依赖，其非约化前缀反例、直接／间接调用边界及证明义务见[独立说明](../../fixes/rsd-nonradical-prefix.md)。

`RCtoSqrfree` 在 `[x²,y³,z²+xy]` 上已有相同参数递归的实现反例。在修复并证明进展前，平方自由分解的全输入终止性及依赖它的纤维算法 C++ 精化义务保持未完成；WRSD 标签正确不能自动解除这一义务。
