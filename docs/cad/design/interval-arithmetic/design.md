# 独立有理区间算术：规格、伪代码与证明

参考 XZ06 §2，使用精确 QQ 端点。本层不含多项式或代数数算法。

## 表示与范围

`rational_interval = [a,b]`，`a,b ∈ QQ` 且 `a ≤ b`。只表示非空、有界闭区间；默认值 `[0,0]`。空交集用 `std::optional` 的空值表示，不能伪造倒置区间。倒置端点在所有编译模式下抛 `invalid_argument`。

XZ06 对跨零除法允许区间并和无穷端点；本模块只表示非空有界闭区间。倒数/除法遇到含零分母时抛 `domain_error`。这不妨碍 XZ06 的多项式估值：它只使用加减乘和有理常量。

公共入口 `clpoly/rational_interval.hh`，只包含 QQ 与 C++ 标准头。区间端点固定为 QQ，避免无舍入保障或整数截断被当作精确区间。

## 函数规格及伪代码

以下 X=[a,b]，Y=[c,d]，`x,y` 表示分别独立取值。

| ID | API | 伪代码及精确语义 |
|---|---|---|
| I01 | 构造、left/right | 若 b<a 抛错；保存 a,b |
| I02 | `X+Y` | `[a+c,b+d]`，恰为 `{x+y}` |
| I03 | `X-Y`, `-X` | `[a-d,b-c]`；`[-b,-a]` |
| I04 | `X*Y` | s={ac,ad,bc,bd}；返回 `[min(s),max(s)]` |
| I05 | `reciprocal(X)` | 若 a≤0≤b 抛错；否则 `[1/b,1/a]` |
| I06 | `X/Y` | `X*reciprocal(Y)`；别名 `X/=X` 也遵循独立取值集合语义 |
| I07 | `pow(X,n)` | n<0 抛错；n=0 返回[1,1]；n奇数返回[a^n,b^n]；n偶数且跨零返回[0,max(a^n,b^n)]；其他偶数返回[min(a^n,b^n),max(a^n,b^n)] |
| I08 | `contains(q/X)`, `interior_contains(q/X)` | 比较相应端点；内部包含使用严格不等式 |
| I09 | `overlaps`, `intersection` | l=max(a,c)，r=min(b,d)；l>r 时空，否则[l,r]；端点接触得到单点交集 |
| I10 | `hull` | `[min(a,c),max(b,d)]`，最小包含区间；不是不连通集合并 |
| I11 | `width`, `midpoint`, `bisect` | b-a，m=(a+b)/2，返回[a,m]和[m,b]；单点允许，调用者不得假设宽度严格减小 |
| I12 | `sign`, `sgn`, `contains_zero` | a>0：positive；b<0：negative；a=b=0：zero；否则 unknown。`sgn` 编码 -1,0,1,2 |
| I13 | `==`, `!=` | 端点相等；不定义区间的全序 `<` |

四则复合赋值先完整计算结果，再写回，保证自别名正确，异常时原对象不变。QQ 标量通过单点区间参与运算。幂指数是有符号整数并检查非负；0 次幂按多项式惯例恒为 1，包括 X=[0,0]。

## 实现细化与运算成本

### I01：端点所有权

双端点构造按值接收 QQ，再移动到成员中；已有端点复制一次，临时运算结果可以移动。合法性检查使用已经构造的成员 `right_ < left_`，不能读取移动后的参数。所有运算结果仍经过这一检查，不存在跳过不变式校验的构造入口。`intersection` 移动自己的局部端点，不修改输入。

### I04：按符号选择极值端点

乘法的集合规格仍是四角极值，但计算只保留可能成为极值的乘积。先检查左端点非负，再检查右端点非正，否则为跨零；`[0,0]` 归入非负类。设 X=[a,b]、Y=[c,d]：

| X 类别 | Y 类别 | 返回端点 |
|---|---|---|
| 非负 | 非负 | `[ac,bd]` |
| 非负 | 非正 | `[bc,ad]` |
| 非负 | 跨零 | `[bc,bd]` |
| 非正 | 非负 | `[ad,bc]` |
| 非正 | 非正 | `[bd,ac]` |
| 非正 | 跨零 | `[ad,ac]` |
| 跨零 | 非负 | `[ad,bd]` |
| 跨零 | 非正 | `[bc,ac]` |
| 跨零 | 跨零 | `[min(ad,bc),max(ac,bd)]` |

前八类执行两次 QQ 乘法；最后一类执行四次乘法和两次极值比较。最后一类用可移动局部 QQ 保存乘积，再移动选中的上下界，不构造 initializer-list。返回结果还要执行构造器的端点顺序检查。

等价性：乘积对固定坐标为线性函数，另一个坐标的符号决定它递增或递减。前八类由这些单调性直接选出四角中的极值；双方跨零时，ad、bc 为负，ac、bd 为正，故只需分别比较这一对负乘积和这一对正乘积。零端点下相同不等式仍成立。

### I07：幂与局部结果移动

按以下顺序处理：负指数抛错；零次幂返回 `[1,1]`；一次幂返回 X；单点区间只计算一次端点幂。其余情况计算两个端点幂，奇次直接按原次序返回，偶次将两个值排序，含零区间再将下界设为零。移动局部端点到返回对象。

一次幂是恒等映射，单点上的值域也是单点，故两个快捷分支满足 I07。它们不改变自别名乘法的独立取值语义：`X*=X` 与 `pow(X,2)` 仍可能不同。

### I12：直接读取符号

QQ 分母恒正，因此 `clpoly::sgn(q)` 读取分子符号即可。`contains_zero` 比较两个端点符号与零；`sign` 用左端点正、右端点负、两端点零三种条件判断。乘法分类使用同一符号接口，避免与 QQ(0) 比较时的交叉乘法。普通端点大小比较仍使用完整 QQ 比较。

## 正确性证明

I01 保证表示不变式。I02/I03 由实数加法单调性得到上下确界。

I04 中双线性函数 xy 在矩形上对每个固定坐标都是线性的，因此极值在四角取得；矩形连通及函数连续保证值域填满两极值间的区间。

I05 的前置条件使 X 完全位于零的一侧；1/x 在该侧连续严格递减，因此值域为[1/b,1/a]。I06 再用 I04 得到除法值域。X/X 通常不等于[1,1]，因为区间算术没有自动记录操作数相关性。

I07 奇幂在实轴单调递增；偶幂关于绝对值单调，跨零时最小值0，最大值在端点。它与重复区间乘法不同：`pow([-1,1],2)=[0,1]`，而独立乘法得到[-1,1]。

I08–I10 由闭区间定义直接得到。I11 两半都包含于原区间，二者并集等于原区间，宽度均为原来一半；这不提供“目标根在哪一半”的证书。I12 返回正/负时整个区间有该符号；返回zero仅限单点0；其余含零情况不推断具体函数值。

所有端点计算使用精确 QQ，不涉及浮点舍入。上述集合运算均具包含单调性：在运算有定义时，缩小输入不会扩大精确值域。本层无无限迭代；幂使用已有 QQ 整数幂算法。后续多项式估值以结构归纳证明包含性，而非假定其结果一定是最紧包络。

## 验证与审核

- 区间头独立编译；不链接 libclpoly，仅链接 GMP。
- 按接口分组，每个用例直接写出输入与期望端点，不使用参考计算器或批量枚举。
- 乘法覆盖九种符号组合；其他用例覆盖零端点、单点、有理分母及超过 int64 范围的端点。
- 幂、集合关系、中点及二分均检查明确的数学结果。
- 测试倒置端点、含零除数（含端点零）、负指数和强异常保证。
- Debug 与 `-DNDEBUG` 均执行上述测试。
- 不以区间包含0判定多项式等于0；不在这一层实现任何选根/精化决策。
