# 完整 CAD 后续形式化规格

目标是将数学规格、算法正确性和 C++ 表示精化连接为机器可检查证明。

表示关系和依赖图定义于 [后续形式化验证接口](../modular-cad/formalization.md)，包括 QQ、区间、三角列、实点、冻结代表与 CAD 树的表示关系，以及各层正确性和终止性依赖。

目标：输出对输入多项式集符号不变的完整柱状代数分解；所有叶胞腔覆盖全空间且互不相交、每个样本在对应胞腔内、记录符号在整个胞腔成立。

[理论 PDF](../../theory/lazard-evaluation.pdf) 给出实点支撑算法、QQ Lazard 以及算法 12–13 完整提升/驱动的数学证明，明确导入可信投影契约及 MPP delineability 定理。后续机器形式化需精化这些导入及 C++ 表示；点上精确求值测试不能替代整胞腔证明。
