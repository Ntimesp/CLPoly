# 文档目录

文档按来源与用途分开存放。历史审查基线是 `origin/CAD_dev`（`1c214ed`）；本轮按初始 `HEAD=5402483` 分功能审核并提交，假设底层满足文献与接口契约。

| 目录 | 内容 | 阅读方式 |
|---|---|---|
| [cad/](cad/README.md) | 基线之后新增的项目文档：完整 CAD 设计、理论、算法与实现对应、基础修复及测试验证 | 本次逐层审查入口 |
| [既有文档索引](existing-docs.md) | 可信基线已有的项目设计、研究、开发日志和修复记录 | 查阅既有模块及历史背景；不与新规格混用 |
| [references/](references/README.md) | 外部论文、阅读笔记、OCR 文本、参考实现和基准资料 | 算法依据与调研材料；不是本项目实现规格 |
| [workflow.md](workflow.md) | 项目开发工作流程 | 项目通用规范 |

已经提交的文档保持原路径和原内容，不作搬迁或删除。`design/`、`research/`、`devlog/`、`fixes/` 中的既有材料通过索引分类；既有论文仍位于 `research/papers/`。

新增项目规格应放入 cad，论文及其摘录应放入 references。当前主线的编号伪代码和人工证明是项目产物，放在 cad/theory，而不是参考文献目录。
