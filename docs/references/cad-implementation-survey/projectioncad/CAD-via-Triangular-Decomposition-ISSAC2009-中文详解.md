## 1. 算法框架

本文 CAD 算法三步流程：

```
输入: 有限多项式集 F ⊂ ℝ[y₁,...,yₙ]

Step 1: Initial Partition
   将 ℂⁿ 分解为互不相交的可构造集，使得每个 f ∈ F
   在每个可构造集上要么恒为零，要么 nowhere 为零

Step 2: MakeCylindrical
   将初始划分转化为柱形分解（满足投影不交或相等的性质）

Step 3: MakeSemiAlgebraic
   从复柱形分解提取实空间 CAD

输出: F-不变 CAD E of ℝⁿ
```

与 Collins 投影-提升方法的核心区别：**先在复空间 ℂⁿ 分解，再提取到 ℝⁿ**。

## 2. Lifting 步骤的核心问题

### 2.1 已知条件

在提升（lifting）时，对于当前层（设为主变量 yₙ）：

- **低维胞腔** `C`：已知其半代数表示和样本点 `α ∈ C`
- **样本点表示**：正则链 `T` + 隔离区间 `L`（即 `(T, L)` 表示）
- **多项式集** `F = {f₁, ..., fₘ}`：每个 `fᵢ` 在 `C` 上是 **delineable** 的

**Delineable 的含义**（Collins 定理）：
- `disc(fᵢ)` 在 `C` 上不变号（不消失）
- `res(fᵢ, fⱼ)` 在 `C` 上不变号（不消失）
- 初式 `init(fᵢ)` 在 `C` 上不变号（不消失）

这保证了：在 `C` 上方，`fᵢ` 的实根个数、重数、以及不同 `fᵢ` 的根之间不交，都是稳定的。

### 2.2 Lifting 的两步操作

为了得到高维胞腔（stack over C），需要：

**Step A：构造多项式基**

将 `F` 转化为一组基 `G = {g₁, ..., gₖ}`，满足：
1. 在样本点 `α` 代入后，`gᵢ(α, yₙ)` 是**无平方的**
2. `gᵢ(α, yₙ)` 之间是**两两互素**的
3. **`G` 和 `F` 的根集相同**（在 `C` 上）
4. **保留对应关系**：能追踪每个 `gᵢ` 来自哪些 `fⱼ`

**Step B：实根隔离**

对 `∏ gᵢ(α, yₙ)` 在 `yₙ` 上做实根隔离，得到有序区间 `I₁ < I₂ < ... < Iₛ`。

每个区间对应一个高维胞腔：
- 奇数索引区间（含根）：截面（section），`yₙ = root`
- 偶数索引区间（不含根）：扇形（sector），`rootᵢ < yₙ < rootᵢ₊₁`

**Step B 我知道怎么做。** 问题在 Step A。

## 3. 问题：如何计算带对应关系的无平方基

### 3.1 一元情况的类比

对于一元多项式 `f(x)`，无平方分解是标准的：

```
f = g₁ · g₂² · g₃³ · ... · gₘᵐ
```

其中 `gᵢ` 两两互素且无平方。

计算方式：
- `g₁ = f / gcd(f, f')`
- `g₂ = gcd(f, f') / gcd(f, f'', g₁)`
- ...

关键是：**我们知道每个 `gᵢ` 的重数，以及 `gᵢ` 和原多项式 `f` 的对应关系**。

### 3.2 多元情况的问题

现在的问题是：在**正则链 + 隔离立方体** `(T, L)` 的约束下，对多元多项式集 `F` 做类似的分解。

具体来说，我们需要：

**输入**：
- 正则链 `T`（零维，样本点 `α` 满足 `T(α) = 0`）
- 隔离立方体 `L`（包含 `α`）
- 多项式集 `F = {f₁, ..., fₘ}`，主变量为 `yₙ`

**已知**：
- `init(fᵢ)` 在 `α` 处不消失
- `disc(fᵢ)` 在 `α` 处不消失
- `res(fᵢ, fⱼ)` 在 `α` 处不消失

**目标**：计算 `G = {g₁, ..., gₖ}` 使得：

1. 每个 `gᵢ` 关于 `sat(T)` 是**无平方的**（即 `ires(sep(gᵢ), T) ≠ 0`）
2. `gᵢ` 之间关于 `sat(T)` **两两互素**
3. `V(F) ∩ Z(T, h) = V(G) ∩ Z(T, h)`（在拟分支上根集相同）
4. **对应关系**：对每个 `gᵢ`，知道它来自哪些 `fⱼ` 的哪些因子

### 3.3 核心难点

在一元情况下，无平方分解通过 **GCD 序列** 实现：

```
f⁽⁰⁾ = f
f⁽¹⁾ = gcd(f⁽⁰⁾, f⁽⁰⁾')
f⁽²⁾ = gcd(f⁽¹⁾, f⁽¹⁾')
...
g₁ = f⁽⁰⁾ / f⁽¹⁾
g₂ = f⁽¹⁾ / f⁽²⁾
...
```

在**正则链模下**，我们需要：

```
f⁽⁰⁾ = f mod sat(T)
f⁽¹⁾ = gcd(f⁽⁰⁾, sep(f⁽⁰⁾)) mod sat(T)
...
```

但这里有几个问题：

**问题 1：GCD 在正则链模下的定义**

正则链 `T` 的饱和理想 `sat(T)` 不一定是主理想。两个多项式在 `sat(T)` 模下的 GCD 如何定义？

论文中使用的是 **pseudo-GCD** 或 **iterated resultant** 的技术。`ires(h, T) ≠ 0` 表示 `h` 关于 `sat(T)` 正则，这保证了可以做除法。

**问题 2：对应关系的丢失**

即使能计算无平方因子，如何知道每个因子来自原多项式的哪个部分？

在一元情况下，这很自然：`g₁ = f / gcd(f, f')` 直接来自 `f`。

在多元情况下，如果 `f = p · q² mod sat(T)`，我们需要：
- 知道 `p` 和 `q` 的表达式
- 知道 `p` 来自 `f` 的"单重部分"
- 知道 `q` 来自 `f` 的"双重部分"

**问题 3：多个多项式的交互**

`F = {f₁, f₂}` 时，不仅要分别对每个 `fᵢ` 做无平方分解，还要确保 `f₁` 的因子和 `f₂` 的因子之间互素。

如果 `f₁ = p · q`，`f₂ = q · r`，则 `q` 是公共因子，需要合并处理。

## 4. 论文中的方法

### 4.1 SeparateZeros 算法

论文的 **Step A** 实际上是通过 **SeparateZeros** 完成的。

核心思想不是直接做无平方分解，而是通过**迭代交**（iterated intersection）来分离零点：

```
输入: 正则系统 rs* = [T*, h*]，yₙ 关于 T* 代数
输出: {(C, P_C)} 分离 Z(rs*)

Step (1): R = {rs*}, P = ∅

Step (2): 从 R 中取 rs = [T, h]
          计算 r = res(h · sep(tₙ), tₙ)  （tₙ 是 T 中 yₙ 的多项式）

          分解: Z(rs) = (V(tₙ) ∩ Z(rsᵤ)) ∪ (Z(rs) ∩ V(r))

          第一部分: V(tₙ) ∩ Z(rsᵤ) → 加入 P（作为 (rsᵤ, tₙ)）
          第二部分: Z(rs) ∩ V(r) → 用 Intersect 得到更低秩的 R'

          R = R ∪ R'，继续直到 R = ∅

Step (3): 用 SMPD 合并所有 Zᵤ(rsᵤ)，得到划分 C
          对每个 C，P_C = 所有满足 C ⊆ Zᵤ(rsᵤ) 的 tₙ
```

**关键观察**：
- 每次迭代，新加入的正则系统**秩严格降低**
- 所以算法必终止
- 输出中的每个 `tₙ` 都是**无平方的**（因为 rs 是 squarefree regular system）
- `init(tₙ)` 在 `Zᵤ(rsᵤ)` 上不消失（由 Lemma 1 保证）

### 4.2 与无平方分解的对应

SeparateZeros 实际上是在做**隐式的无平方分解**：

- 输入的 `tₙ` 可能有重因子
- 通过 `res(h · sep(tₙ), tₙ)` 和 Intersect 操作，逐步"剥离"不同重数的部分
- 最终输出的每个 `tₙ` 对应一个**无平方因子**

但论文**没有显式保留**每个 `tₙ` 和原多项式的对应关系。它只保证了：
- `Z(rs*) = ⨆ V(tₙ) ∩ πᵤ⁻¹(Zᵤ(rsᵤ))`
- 每个 `tₙ` 在其定义域上无平方且两两互素

### 4.3 对应关系的缺失

这是当前困惑的核心：

> 论文的 SeparateZeros 给出了无平方的 `tₙ`，但没有告诉我们每个 `tₙ` 对应原多项式的哪个因子、重数是多少。

对于 CAD 的**符号判定**（sign-invariant），这足够了——我们只需要知道每个 cell 上多项式的符号。

但对于**阶不变**（order-invariant）或需要知道**根的重数**的应用，对应关系是必要的。

## 5. 待解决的问题

### 5.1 技术问题

如何在正则链模下，像一元多项式那样计算**带对应关系的无平方分解**？

具体来说，给定 `f` 和正则链 `T`，计算：

```
f ≡ g₁ · g₂² · g₃³ · ... · gₘᵐ  (mod sat(T))
```

其中 `gᵢ` 关于 `sat(T)` 无平方且两两互素，并且：
- 知道每个 `gᵢ` 的重数 `i`
- 知道 `gᵢ` 和原多项式 `f` 的对应关系

### 5.2 可能的思路

**思路 1：直接推广一元 GCD 序列**

在正则链模下定义 pseudo-derivative 和 pseudo-GCD：

```
f⁽⁰⁾ = f
f⁽¹⁾ = gcd_mod_RC(f⁽⁰⁾, sep(f⁽⁰⁾), T)
f⁽²⁾ = gcd_mod_RC(f⁽¹⁾, sep(f⁽¹⁾), T)
...
g₁ = f⁽⁰⁾ / f⁽¹⁾ mod sat(T)
g₂ = f⁽¹⁾ / f⁽²⁾ mod sat(T)
...
```

问题：`gcd_mod_RC` 如何在正则链模下定义？`sep(f)` 是关于 `yₙ` 的偏导，但正则链模下的除法需要处理初式。

**思路 2：利用迭代结式（iterated resultant）**

论文中 `ires(h, T)` 已经提供了判断正则性的工具。能否用它来控制分解过程？

**思路 3：在样本点局部做分解，再提升**

既然我们已经有样本点 `α`，可以在 `α` 的局部环上做分解，然后验证分解在整個 `C` 上有效。

### 5.3 与 ProjectionCAD 的对比

ProjectionCAD（McCallum 投影）的做法：

1. 投影阶段计算判别式、结式，得到投影多项式集
2. 提升时，对**每个 cell** 上的**每个投影多项式**，判断是否在样本点消失
3. 如果消失，用 **minimal delineating polynomial** 替代
4. 对未消失的多项式，直接在样本点代入后做**一元实根隔离**

关键区别：ProjectionCAD 不需要显式的无平方分解——它直接在样本点做一元分解，因为样本点代入后多项式变成真正的一元多项式。

但三角分解方法（本文）需要在**符号层面**做分解（在正则链模下），因为样本点是由正则链隐式表示的代数数。

## 6. 附录：关键定义

**正则链**：三角集 `T` 满足 `ires(h_T, T) ≠ 0`

**正则系统** `[T, h]`：`T` 是正则链，`ires(h, T) ≠ 0`

**迭代结式**：
- `ires(h, T) = h`（若 `h` 无代数变量）
- `ires(h, T) = ires(res(h, tᵥ, v), T<ᵥ)`（否则，`v` 是 `h` 中最大的代数变量）

**拟分支**：`W(T) = V(T) \\ V(h_T)`

**可构造集**：`Z(T, h) = W(T) \\ V(h)`
