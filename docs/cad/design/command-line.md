# CAD 命令行程序

## 输入、输出与边界

`clpoly-cad` 直接接受现有三数据集 TXT 格式：第一段一行变量表，第二段每行一个 QQ 多项式，第三段每行一个 CNF 子句，段间以空行分隔。变量表为投影顺序；全部变量取实数。多项式和原子均从零编号，`[i,=]`、`[i,>]`、`[i,<]` 比较第 i 个多项式与零。`|` 表示或，子句逐行取且。

默认输出单行 `SAT` 或 `UNSAT`，含义是存在／不存在满足整个公式的实数赋值。数学题的候选答案、反例或界已经编码在查询中；本程序不从自然语言猜测待求量，也不将一个有解样本当作唯一数学答案。

`--sample` 在 SAT 后输出一个解的精确证书：提升坐标顺序、QQ 正则链、各坐标的严格有理隔离区间及固定平移。链和隔离盒共同指定唯一实点，区间端点不是近似答案。`--reverse` 使用变量表反序投影。`--check` 只检查输入，输出 `VALID`，不求解；不能与 `--sample` 合用。文件名 `-` 从标准输入读取。

正常 SAT／UNSAT／VALID 返回 0，命令行、文件和格式错误返回 2，求解异常返回 1。诊断写入标准错误；格式错误或求解失败不输出 UNSAT。不设置内部求解时间限制，基准调用者可对整个进程设置外部限时。底层算法沿用当前库契约和单列的已知问题，见[底层记录](../fixes/rsd-nonradical-prefix.md)。

## 表达式语法与校验

```text
sum     := product { ('+' | '-') product }
product := unary { ('*' | '/') unary }
unary   := { '+' | '-' } power
power   := primary [ ('^' | '**') nonnegative_integer ]
primary := integer | declared_variable | '(' sum ')'
atom    := '[' nonnegative_integer ',' ('=' | '>' | '<') ']'
clause  := atom { '|' atom }
```

幂优先于一元负号，因此 `-x^2` 是 `-(x^2)`。指数是非负十进制整数字面量；不接受链式幂或负指数。除数必须经精确规范化后为非零 QQ 常量，允许 `x/3`、`x/(1+2)`，拒绝 `x/y`、`x/0`。不支持隐式乘法、浮点数、函数调用、量词或执行脚本。

整数通过十进制字符串进入 ZZ，运算使用 QQ，禁止浮点中转。变量必须声明、无重复；名字以字母、下划线或非 ASCII 字节开头，后接这些字符或数字，按原文本字节精确匹配。兼容 CRLF 和开头 UTF-8 BOM。每段非空、变量段只有一行；真／假常量公式可分别写为 `0=0`／`0>0` 并保留一个自由变量。

解析时检查子句引用、完整消费输入、指数及中间总次数不超过库的 `int64_t` 表示。乘法前检查次数和，求幂前检查次数乘积；表达式括号最多嵌套 256 层，超限报格式错误。不能靠 Release 中被关闭的断言验证外部文本。

## 数据与算法

`tools/cad_input.hh` 的 `formula_atom`、`cad_formula` 只保存引用、变量、多项式和子句。表达式扫描状态只保存文本、变量表、位置及嵌套深度；扫描、表达式运算、CNF 读取和符号判断均为自由函数。类型与函数放在工具命名空间，不增加库总头的公共接口。

`read_formula` 将文本检查并解析成普通 QQ 多项式，`full_cad` 的公共入口继续负责检查、换序和调用字典序内核。工具不直接调用内部 `__` 内核，不重复实现投影、Lazard、代数点或根隔离。当前路径直接构建全空间 CAD，不将实验中的线性预处理悄悄接入求解。

表达式按语法结构归纳解释：整数和已声明变量对应其本值，环加减乘及非负整数幂保持取值；除法只使用非零 QQ 常量的逆元。原子引用已检查，因而子句与输入公式对应。

在每个叶胞腔，`formula_holds` 按原输入符号表计算 CNF。若某叶为真，认证样本给出 SAT 见证；若全部叶为假，由完整覆盖和每胞腔符号不变得到 UNSAT。这里使用[完整 CAD 的文献论证](modular-cad/lazard-and-cad.md)，新代码只实现精确语法解释及有限布尔求值，不引入新的代数算法。

结果及样本只在 `full_cad_result` 存活期间使用；打印证书时同时输出变量表，避免把投影顺序误作样本坐标顺序。

## 构建与验证

`make cad` 生成 `_build/release/bin/clpoly-cad`，使用项目编译器和 Release 静态库，只需既有 GMP／Boost 环境，运行不依赖 Python 或 Z3。`make test-cad-cli` 运行解析／布尔单元测试与命令行端到端测试，后者使用 Python 标准库驱动进程。

测试包括精确 QQ、优先级、括号、任意精度整数、指数边界、未声明／重复变量、非法分母及子句、CRLF／BOM、标准输入、反序、SAT／UNSAT、无理数见证、进程退出码，以及原始归档 72 个 TXT 的格式兼容。测试数据只读归档，不覆盖历史实验。
