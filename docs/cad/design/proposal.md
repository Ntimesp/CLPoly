# 完整 CAD：QQ、独立区间与三角列实现方案

本设计实现有理多项式输入的完整符号不变 CAD。实代数点算法依据 XY16/XZ06，三角列分解复用 `charset.hh`，有理数使用现有 QQ。数据结构管理表示与所有权，算法通过独立函数操作这些数据。

## 技术路线

`ZZ → QQ → 独立区间`；`QQ 多项式 → 三角列`；两者在实代数点层组合，最后实现 QQ Lazard 求值与完整投影提升。

三角列描述方程，QQ 隔离盒选择实解。表达式保持 QQ 系数及形式变量，通过实点判零和符号接口解释。不得把正则商环视为域，不将无理数直接代入库的系数类型。

## 核心正确性决策

1. 区间加减乘除使用精确 QQ 端点；含零分母拒绝。区间包含零不是点值等于零。
2. 三角列分解通过 XY16 WRSD 等原有算法；独立封装负责对象生命周期、变量序及契约检查。
3. 指定点判零先分解为零/非零分支，再用 XZ06 保根精化排除不含该点的分支。
4. XZ06 隔离检查正则、平方自由、正半轴平移及完整配对条件。界多项式只给包络，不成为目标根定义式。
5. Lazard 在 QQ 代表上连续求导和前缀判零，除阶乘后冻结变量；不提前模活动变量的定义方程。
6. 纤维根隔离先限制首项分支，以免其他共轭分支出现恒零纤维，破坏零维假设。
7. 每个父胞腔生成全部 Section/Sector；叶符号用原输入的普通点值，不用 Lazard 值代替。

## 实施边界

已提供模块化算法实现及回归验证；机器形式化证明尚未完成。继承的分解、结式、因式分解、Uspensky 和投影实现仍是后续证明依赖。当前实现仅在所选前缀上提升纤维，复用已验证的前缀证书；投影分解、代表乘积及高次数根隔离仍需正式实验，不宣称工业级大规模性能。

## 实验、项目交付与形式化阶段

算法和接口完成逐层人工审核后，先开展正式实验，再编写项目交付文档，最后完成机器形式化验证。

实验须分别计时投影、分解、重编码、隔离/精化、判零/符号和树构建，记录输入、变量序、构建配置、超时/失败类别、候选数、根数、胞腔数及峰值内存。几何或解析预期用于独立校验；不能只凭胞腔总数或样本符号认定两个 CAD 相同。现有小规模诊断保存在对应模块设计中，不替代正式基准。

项目交付文档在接口和实验冻结后编写，明确支持 QQ 多项式上的完整符号不变 CAD。通用代数数域四则与量词消去不列为已实现能力。

形式化依照[模块证明接口](modular-cad/formalization.md)，分别处理 ChainRep、PointRep、前缀特化代表及来源身份一致的 TreeRep，证明分解覆盖、保根收敛、Taylor 提取、指定纤维根集、完整栈和 MPP 归纳。论文定理、基线算法及 C++ 迭代器/比较器/大整数的导入与精化义务均须显式列出。
