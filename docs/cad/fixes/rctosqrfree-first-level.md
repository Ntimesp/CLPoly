# RCtoSqrfree：首层平方自由契约

## 数学要求

XY16 Algorithm 3.1（书页 62）查找判别式沿前缀结式为零的最大层，范围包含第一层。只有所有层均满足平方自由条件时才直接返回输入。此契约适用于零维正则链，包括单方程链和空链。

## 实现

`clpoly/charset.hh::RCtoSqrfree` 的零基索引扫描条件为 `k >= 0`；扫描结束后仅 `k < 0` 表示不存在待处理层。`k == 0` 表示第一层需要分解，必须进入子结式、伪商与递归流程。第一层的前缀为空，前缀 prem/res 操作为恒等操作。

这种区分是对可信基线的局部修改：将“第一层待处理”与“所有层均通过”映射到不同状态。包装器 `squarefree_decomposition` 还检查输出正则及平方自由，但包装检查不能代替 XY16 算法证明。

## 回归与审查

回归用例分别输入 `[(x-1)^3(x+2)^2]` 和 `[(x-1)^3(x+2)^2, y-x]`。期望结果分别为 `[(x-1)(x+2)]` 和 `[(x-1)(x+2), y-x]`，直接比较输出方程。伪除法允许引入非零常数因子，因此第一条方程取本原部分 `pp` 后比较。先检查结果形状，再访问元素，避免失败时越界。

用例位于 `test_charset.cc` 与 `test_regular_chain.cc`；实测结果见[验证报告](../reports/modular-cad.md)。实现对应以 XY16 原文为准，没有运行作者 Maple 程序进行交叉验证。
