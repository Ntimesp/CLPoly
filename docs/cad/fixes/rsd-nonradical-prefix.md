# 三角列底层契约与待办

本轮按用户要求假设已提交 `charset.hh` 满足文献契约，只审核 `regular_chain.hh` 的适配。底层已知实现缺陷留待后续处理，不作为包装器缺陷，也不修改底层实现。

## 使用的契约

依据 Xia–Yang 2016 Definition 2.11、Algorithm 2.2、Theorem 2.6（pp.38–44），WRSD 接受零维正则链和当前链变量上的多项式，返回有限正则链列表 H、G，分别覆盖零集与非零集。零分支不保证伪余式为零，分支不保证平方自由，也不要求同标签分支互不相交。公开包装器检查坐标后清正分母，内部入口仅使用断言。

平方自由分解使用同书 Algorithm 3.1、Theorem 3.2（p.62）的同坐标、正则平方自由、零集完整覆盖及终止契约。原有 RSD 接口保留，但新增包装器不调用它；WRSD 不被当作 RSD 的强契约使用。
